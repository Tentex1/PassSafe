# Security Policy

## Supported Versions

PassSafe is currently in its initial release. Only the latest major versions receive active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Since PassSafe is an offline password manager, security and privacy are our top priorities.

If you discover a critical security vulnerability or a cryptography flaw within PassSafe, please **DO NOT** create a public issue on GitHub. Exposing vulnerabilities publicly puts other users at risk.

Instead, please report it privately by sending an email to:
📧 **[drnyvz2@gmail.com]**

### What to expect:
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will work with you to understand and resolve the issue safely.
- Once the vulnerability is patched, we will publicly acknowledge your contribution and responsible disclosure (if you agree to it).

Thank you for helping keep PassSafe and its users secure! 🛡️
